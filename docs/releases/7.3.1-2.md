## AywGram

### 简体中文

- 更新 macOS 应用图标与品牌资源，修复钱包绑定源码在 CI 依赖裁剪中丢失的问题。
- 在 Telegram 7.3.1 基线上独立适配下述 AyuGram 修复，保留 AywGram 更新器、防截图、语言包和异步发送流程；插件元数据转义和不完整输入处理进一步加固。
- 本地验证目标为 macOS ARM64 Release。未进行登录账户、真实消息或界面回归测试。

### English

- Update macOS icons and branding, and preserve generated wallet bindings during CI dependency pruning.
- Independently adapt the AyuGram fixes below to Telegram 7.3.1 while preserving the AywGram updater, screenshot protection, language packs, and asynchronous sending. Further harden plugin metadata escapes and incomplete inputs.
- Local validation targets macOS ARM64 Release. Account, real-message, and UI regression testing has not been performed.

## AyuGram

### 简体中文

以下为截至 [d4b7546e77](https://github.com/AyuGram/AyuGramDesktop/commit/d4b7546e77f93ac4c9bb53a3fcf7e9ffbbecf1b5) 的选择性重实现，元数据范围仅表示审阅来源，不表示合并了全部提交。

- 修复数据库并发访问、手动已读请求收尾和 Ghost 切换导致的请求状态丢失。
- 修复限时媒体动画生命周期和保存后的显示刷新，以及 macOS Ghost 菜单状态更新。
- 外部翻译服务正确接收富文本摘要；限制危险外部协议，插件描述链接仅允许 HTTP、HTTPS 和 tg。
- Ghost 调度避开 ephemeral 回复/命令，Saved Music 补齐伪回复及表情规范化，保留 ephemeral 的真实禁止转发标志。
- 富文本转发支持 File block，并过滤无法序列化的按钮；修复 GIF/贴纸确认场景、TTL 按钮刷新、欢迎消息截图和 WebView 平台/初始尺寸。

### English

These are selective independent adaptations reviewed through [d4b7546e77](https://github.com/AyuGram/AyuGramDesktop/commit/d4b7546e77f93ac4c9bb53a3fcf7e9ffbbecf1b5). The metadata range identifies reviewed sources, not a full upstream merge.

- Fix concurrent database access, manual-read completion, and request-state loss when switching Ghost settings.
- Fix TTL animation lifetimes, refresh retained media after consumption, and update macOS Ghost menu state.
- Route rich summaries to the chosen external translator; restrict unsafe external protocols and allow only HTTP, HTTPS, and tg in plugin description links.
- Keep ephemeral replies and commands out of Ghost delays, handle pseudo-replies and premium emoji in Saved Music, and preserve the actual ephemeral noforwards flag.
- Support File blocks and serializable buttons in rich forwarding; fix GIF/sticker confirmation contexts, TTL control refresh, welcome-message screenshots, and WebView platform/initial sizing.
