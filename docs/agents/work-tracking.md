# Agent 任务记录

读者：执行任务的 Agent。记录由 Agent 随工作更新，人类无需直接维护；其中的目标与约束仍以用户指示为准。

为复杂功能、重要 bug、跨轮次工作和重要维护任务，在 `docs/agents/tasks/YYYY-MM-DD-topic.md` 建立一份可提交的记录。小改动使用 Git 历史即可，不为每次工具调用或每个提交建文档。

开始工作时先按当前主题检索 tasks，并查看相关 active/blocked 记录，优先续写已有文件；无需加载所有已完成任务。

记录包括目标、状态、关键决策、执行计划、验证结果和后续事项；bug 补充复现条件与根因。状态使用 `planned`、`active`、`blocked`、`completed` 或 `cancelled`。开始工作、关键决策改变和交付时更新同一文件，完成后保留路径。说明未完成项，不把静态验证写成构建或运行成功。

保存能帮助后续接手的结论、提交和证据链接，避免复制聊天、命令流水账或完整 diff。永久性规则写进相应规范，任务记录只链接过去。引用 `out/` 时说明它是本地证据，不能作为其他 checkout 唯一可用的解释。

需要版本控制的计划与任务结论放在本目录；临时方案、审计原始数据和执行日志遵循 [out 目录约定](out-layout.md)，不提交。不得保存凭据、会话、私有地址或用户消息。
