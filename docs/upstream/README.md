# 上游参考资料

[telegram-changelog.txt](telegram-changelog.txt) 是 Telegram Desktop 官方日志的独立副本，保留原有格式和历史；初始副本来自本仓库已纳入的 Telegram 7.3.1。

上游同步时从实际纳入的 Telegram 提交提取该文件，记录来源提交，并将上游在根目录的 changelog 修改归入此副本。根目录 [changelog.txt](../../changelog.txt) 归 AywGram 所有，不接受上游日志覆盖。基础版本维护脚本读取官方副本；Ayw 发布页和 AppStream 读取根日志。

发布说明仅汇总已实际纳入的改动；当前上游网站或分支的最新内容不代表本项目已经包含它。官方完整历史见 [Telegram Desktop changelog](https://github.com/telegramdesktop/tdesktop/blob/dev/changelog.txt)。
