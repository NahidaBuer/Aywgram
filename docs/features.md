# AywGram 功能与来源

[English](features.EN.md) · [功能变更日志](change-log.md)

本文梳理 AywGram 相对 Telegram Desktop 的差异化功能，并说明实现进入本项目的路径与已知 idea 来源。核验基线为 2026-09-11 的 `102ecf4494`；普通 Telegram Desktop 功能不重复罗列。

## 来源标记

| 标记 | 含义 |
| --- | --- |
| AywGram 原创 | 在 AywGram 本地维护线首次发现，提交和源码未注明来自其他客户端。这里描述的是本项目的实现来源，不是排他的发明权声明。 |
| 外部 idea | 提交信息、共同作者或源码注释明确指出其他客户端；本项目通常重新适配到当前 Telegram Desktop 架构。 |
| Ayu 上游 | 从 AyuGram 历史和 `ayu` 源码体系继承；其中少数 idea 在 Ayu 历史里另有第三方致谢，详见“明确借鉴的 idea”。 |
| Telegram 上游 | Telegram Desktop 官方实现；仅在容易被误认为 AywGram 独有功能时单独说明。 |
| 混合 | 主体来自上游或外部 idea，AywGram 又加入了独立扩展。 |

归属证据的优先级依次为：项目维护者的一手说明，明确的提交说明、共同作者或源码注释，功能引入提交及文件历史，最后才是当前源码差异。无法由现有信息确认的内容不会猜测来源。

## 从 Ayu 上游继承的主体能力

AywGram 在 `4e36649704` 中把本地维护线、Ayu 基线 `8e18cb7110` 和当时的 Telegram Desktop 基线汇合。以下是当前仍由 Ayu 体系承载的主要能力；上表已单列 Ayu 历史中明确致谢其他客户端的项目。

- 幽灵模式及其网络行为控制：消息/Story 已读、在线、输入和上传状态、自动离线、交互后已读、幽灵定时发送、静音发送、每账号与全局配置。
- 本地消息数据库：防撤回、编辑历史、附件保存与限额、已读日期、推测最后在线、数据库导入导出。
- 正则消息过滤和 Shadow Ban：共享/会话规则、排除规则、导入导出、屏蔽用户内容过滤。
- AyuForward 与消息快捷操作：重复发送、无引用/无标题转发、发送为贴纸、转发进度与相关上下文菜单。
- 消息截图：主题、背景、日期、反应、顶栏装饰、彩色回复和 spoiler 展示选项。
- 外观与入口定制：主题、字体、头像和气泡圆角、图标、通知角标、文件夹、消息字段、抽屉、托盘、频道底部按钮和 WebView 尺寸/UA。
- 主播模式、本地 Premium 外观、Google/Yandex 翻译、macOS Force Click 媒体预览与触觉反馈。
- 消息与账号诊断信息：Peer ID、消息详情、创建/加入/阅读日期、数据中心、贴纸包作者，以及阅后即焚媒体相关控制。
- 界面精简和防误触：隐藏广告、Story、相似频道、Premium 状态、分享按钮和自定义背景，以及贴纸/GIF/语音/圆形视频发送确认。

这些功能可从 `Telegram/SourceFiles/ayu/`、`AyuSettings`、英语 `ayu_` 字符串，以及 `AyuGram` 远端历史交叉核验。当前 `ayugram/dev` 比本项目采用的 Ayu 基线更新；尚未同步的上游功能不属于本文的“当前能力”。

## Telegram 上游能力

WEB 代理（内置 WebView 承载传输并提供浏览器回退）目前属于 Telegram Desktop 上游实现，本项目随 Telegram 更新继承并在 README 中突出说明，不列为 AywGram 原创或 Ayu 原创。富文本编辑器等底层框架也来自 Telegram Desktop；AywGram 的 Markdown 入口和导入流程调整才属于上文列出的差异功能。

## 使用边界

- 幽灵模式、防撤回和本地已读/在线记录是客户端侧行为，不保证 Telegram 服务端或其他客户端永远不可观察，也可能随服务端协议变化失效。
- 本地 Premium 只改变本机显示，不会提高账号额度，也不会让其他用户看到本地样式。
- session string 与 Mithka JSON 包含完整授权密钥；得到文件的人可能无需短信验证码即可登录账号。
- 云设置备份位于 Telegram Mini App CloudStorage，并非端到端加密；代理地址和凭据只有显式启用“同步代理”后才会写入。
- URL 自动 Inline Bot 查询默认关闭，启用前会提示：匹配到的 URL 会发送给规则指定的第三方 Bot。
- 设置名称和入口会随 Telegram/Ayu 同步调整；判断功能是否仍存在应以当前源码和设置页为准。
